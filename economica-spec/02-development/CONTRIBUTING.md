# Contributing

Thank you for your interest in Economica.

## Development Philosophy

Every change should improve one or more of:

- Clarity
- Testability
- Explainability
- Modularity

## Workflow

1. Create a feature branch.
2. Update specifications if architecture changes.
3. Implement the feature.
4. Add or update tests.
5. Ensure the project builds.
6. Open a pull request.
