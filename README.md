# Economica

> A scientific framework for understanding complex economies.

## Overview

Economica is an open-source Java framework for transforming observations into scientific knowledge.

Rather than focusing on dashboards or reports, Economica builds an evolving world model capable of supporting research into complex economic systems.

The framework is designed to be domain-independent.

The first supported domain is Old School RuneScape (OSRS), but the architecture is intended to support any sufficiently complex economy.

---

## Core Ideas

Observations become evidence.

Evidence supports inference.

Inference produces knowledge.

Knowledge updates the World.

The World enables scientific research.
